GameSync Launcher

About GameSync

GameSync Launcher is a personal, non-commercial project designed to synchronize video game save files across multiple devices.

The application uses Google Drive to securely store and synchronize game save backups belonging to the authorized Google account.

Privacy

GameSync Launcher is intended for personal use. It does not sell personal information or share game save data with third parties for advertising purposes.

Google Drive access is used exclusively to manage game save backups authorized by the user.

For more information, please read our Privacy Policy.
